# Apptrak

Binary distributions for Apptrak.

## macOS Apple Silicon

```bash
curl -fsSL https://raw.githubusercontent.com/aematosy/apptrak-releases/main/install.sh | bash
```

Then run:

```bash
apptrak
```

## Windows x64

Open PowerShell and run:

```powershell
irm https://raw.githubusercontent.com/aematosy/apptrak-releases/main/install.ps1 | iex
```

Then open a new PowerShell terminal and run:

```powershell
apptrak
```

## Supported platforms

- macOS Apple Silicon / ARM64
- Windows x64

The Apptrak source code is maintained separately.
